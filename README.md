## 🎯 ¿Qué es Bug Hunter Academy?

**Bug Hunter Academy** es un proyecto educativo integral diseñado para aprender a depurar, programar y resolver errores (conocidos como *bugs*) tanto en el código como en circuitos electrónicos. 

### ¿Por qué surge este proyecto?
Muchas veces, al empezar a programar o armar circuitos, nos enfrentamos a pantallas que no encienden, códigos con errores o resistencias mal calculadas. Este proyecto enseña de forma práctica y divertida a diagnosticar y solucionar cada uno de estos problemas paso a paso.
